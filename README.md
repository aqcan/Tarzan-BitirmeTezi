# Tarzan - 2D Platform Oyunu

Manisa Celal Bayar Üniversitesi, Yazılım Mühendisliği lisans bitirme tezi kapsamında Unity ile geliştirilmiş 2 boyutlu bir platform oyunu (Danışman: Prof. Dr. Akın Özçift, 2025).

Oyuncu tek bölümlük haritada, iki nokta arasında devriye gezen düşmanlara yakalanmadan coin toplar. 20 coin toplandığında oyun başarıyla biter; bir düşmana değerse "Retry" ekranına düşer.

## Özellikler

- Yatay hareket, zıplama ve koşma animasyonları (Unity 2D fizik)
- Point A - Point B arasında devriye gezen düşmanlar
- Coin toplama ve ekranda coin sayacı
- Parallax arka plan
- Ana menü, oyun, tekrar dene ve bitiş sahneleri

## Kontroller

- `A` / `D` veya yön tuşları: sağa-sola hareket
- `Space`: zıplama

## Çalıştırma

1. Unity Hub ile **Unity 2022.3.54f1** (URP) sürümünü kurun.
2. Bu repoyu klonlayıp Unity Hub'da "Add project from disk" ile açın.
3. `Assets/Scenes/Menu.unity` sahnesini açıp Play'e basın.
